# House Price Prediction 🏠

An end-to-end Machine Learning web application that uses an **XGBoost Regressor** model to predict house values based on 13 structural and neighborhood characteristics metrics.

### 🚀 Live Web Application
You can test the live interactive application here: 
👉 [Launch Live App Engine](https://housepriceprediction-jstuzg3dhvfeqzngxgew7a.streamlit.app/)

### 🛠️ Tech Stack
* **Frontend UI:** Streamlit Framework
* **ML Model:** XGBoost Regression Algorithm
* **Data Core:** Numpy & Scikit-Learn
